# Blue Guardian Agent — Threat Intelligence Data Contracts
## AegisMesh 2.0 Subsystem Design Specification (Step 09.2.3.1)

---

## 1. Overview & Data Invariant Guarantees

This document specifies the strict Pydantic v2 data models, validation invariants, serialization formats, and classification taxonomies for the **Blue Guardian Agent**.

### Strict Architectural Invariants
1. **Schema Immutability & Forbid Extra**: All models enforce `model_config = ConfigDict(extra="forbid", frozen=True, validate_assignment=True)`. Arbitrary or undocumented properties are strictly rejected.
2. **Deterministic Typing**: All identifiers are typed as UUIDs or constrained strings (`Field(min_length=..., max_length=...)`). All timestamps are UTC-enforced `datetime`.
3. **Four-Tier Epistemic Taxonomy**: Every data point produced or consumed by the defensive engine is strictly classified into one of four epistemic tiers:
   - **Observed Synthetic Evidence (`OBSERVED`)**: Raw, immutable telemetry directly generated by Red Team simulation runs or target asset responses.
   - **Derived Detection Results (`DERIVED`)**: Direct deterministic outputs produced by applying detection rules to observed telemetry.
   - **Inferred Attack Relationships (`INFERRED`)**: Contextual hypotheses, topological graph traversals, and multi-stage correlations.
   - **Defensive Recommendations (`ADVISORY`)**: Actionable, human-gated remediation and hardening instructions.

class DefensiveEventEnvelope(BaseModel):
    """
    Normalized, immutable envelope for ingested synthetic attack telemetry.
    Classification: OBSERVED
    """
    model_config = ConfigDict(extra="forbid", frozen=True)

    envelope_id: UUID = Field(default_factory=uuid4, description="Unique envelope identifier")
    source_event_id: str = Field(..., min_length=1, max_length=128, description="Originating SimulationEvent ID")
    attack_run_id: UUID = Field(..., description="Foreign key to originating AttackRun")
    sandbox_id: UUID = Field(..., description="Foreign key to originating SandboxEnvironment")
    scenario_id: str = Field(..., min_length=1, max_length=128, description="Scenario identifier")
    timestamp: datetime = Field(..., description="Event timestamp in UTC")
    event_type: str = Field(..., min_length=1, max_length=64, description="Standardized event type")
    source_asset_id: Optional[str] = Field(None, max_length=128, description="Synthetic asset initiating action")
    target_asset_id: Optional[str] = Field(None, max_length=128, description="Synthetic asset receiving action")
    payload: Dict[str, Any] = Field(default_factory=dict, description="Raw synthetic telemetry payload")
    is_simulated: Literal[True] = Field(True, description="Strict synthetic invariant")
    simulation_only: Literal[True] = Field(True, description="Strict synthetic invariant")
    sha256_hash: str = Field(..., min_length=64, max_length=64, description="Cryptographic integrity digest of payload")
    classification: Literal[EpistemicClassification.OBSERVED] = EpistemicClassification.OBSERVED

    @field_validator("sha256_hash")
    @classmethod
    def validate_sha256(cls, v: str) -> str:
        if not all(c in "0123456789abcdefABCDEF" for c in v):
            raise ValueError("sha256_hash must be a valid 64-character hexadecimal string")
        return v.lower()

class DetectionRule(BaseModel):
    """
    Deterministic specification for a defensive detection rule.
    Classification: DERIVED
    """
    model_config = ConfigDict(extra="forbid", frozen=True)

    target_scenario_id: str = Field(..., min_length=1, max_length=128)
    mitre_tactic: str = Field(..., min_length=1, max_length=64)
    mitre_technique_id: str = Field(..., pattern=r"^T[0-9]{4}(\.[0-9]{3})?$")
    severity: DetectionSeverity
    confidence_weight: float = Field(..., ge=0.0, le=1.0)
    predicate_expression: str = Field(..., min_length=3, max_length=512, description="Evaluated deterministic predicate")
    classification: Literal[EpistemicClassification.DERIVED] = EpistemicClassification.DERIVED
